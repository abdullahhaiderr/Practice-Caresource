## Contact and PHI limitations

- The public email is info@practicecaresource.com.
- The consultation form currently creates a mailto draft. The visitor must review the draft and press Send in their own email application.
- The website does not send email in the background, cannot confirm delivery, and has no contact API, Resend integration, lead database, or server-side lead storage.
- The form is a business enquiry channel only. Its browser-side PHI checks are limited and cannot guarantee detection. Do not use it to transmit patient information.
- The supplied phone number was not published because it is incomplete and unverified. No dummy number is presented as a real contact number.
- No physical street address is currently published.

## SEO, security, and infrastructure findings

- Page metadata, canonical path definitions, sitemap.xml, robots.txt, and structured-data helpers are present.
- Security headers in next.config.ts include Content-Security-Policy, HSTS, X-Content-Type-Options, X-Frame-Options, Referrer-Policy, Permissions-Policy, COOP, and CORP.
- The CSP includes upgrade-insecure-requests and the response config includes HSTS. A successful live HTTP-to-HTTPS redirect test has not been performed.
- The current business URL fallback is https://practice-caresource.vercel.app.
- practicecaresource.com is not currently attached to the connected Vercel project. The project domain listing contains only the Vercel hostname. The custom domain must be attached and DNS/HTTPS verified before switching canonical URLs and sitemap output to it.
- The Vercel project has SSO protection enabled for non-custom domains, which may prevent unauthenticated visitors from viewing Vercel preview URLs.
- The earlier deployment for commit 7911cef failed because of a missing Link import; that import is fixed in the current main source. Vercel subsequently produced a READY production deployment for commit 89924a5 and assigned the alias practice-caresource.vercel.app. That deployment predates the later lint fixes and CTA updates. For newer commits, GitHub's Vercel status reports "Deployment rate limited — retry in 24 hours". The current main source passes GitHub CI but has not yet been deployed to Vercel. The Vercel project setting reports Node.js 26.x while GitHub Actions uses Node.js 22; align and validate these build runtimes before the next release.
- npm ci reported 10 moderate severity vulnerabilities and peer-dependency warnings because ESLint 10 is newer than the peer range declared by some Next.js ESLint plugins. A full npm audit triage and dependency compatibility cleanup remain outstanding.
